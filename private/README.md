# private/

Local-only folder. Everything here except this file is **git-ignored** and must never be committed or published.

Put raw source documents here so the coding assistant can read them locally when needed:

- the full CV (contains a phone number),
- the cover letter,
- ETIC commercial proposals and any client document (confidential, "all rights reserved", contain names of third parties and prices).

The coding assistant: use these files only to check facts. Do not copy their text, names, figures or prices into `content/`, `docs/` or the site. See `docs/content-guidelines.md`.
